# КАДР & СЕНС

**Кино, которое думает.** Нативная macOS-студия для создания киноэссе: от локального фильма до смонтированного выпуска, двух вертикальных шортсов и публикации.

[Презентация и руководство](https://se1dhe.github.io/shortcuts/) · [Исходный код](https://github.com/se1dhe/shortcuts)

## Что умеет студия

Приложение ведёт проект по единому маршруту **Фильм → Эссе → Шортсы → Постинг**.

1. **Фильм.** Откройте локальное видео и выберите аудиодорожку. Субтитры SRT/VTT можно взять из папки фильма; при необходимости доступна транскрипция WhisperKit.
2. **Киноэссе.** Director анализирует диалоги, выбирает центральную тему и строит пятиактную структуру. Модель подбирает сцены по их роли в аргументе и добирает материал отдельными запросами, если исходного набора не хватает. Смысловая проверка помогает заменить неподходящую тему.
3. **Редакторы.** Проверьте сцены и акты в монтажном столе, исправьте субтитры с предпросмотром, отправьте текст на редакторский проход или пересоберите сцены с AI на той же теме.
4. **Шортсы.** Подготовьте два разных ракурса темы из финального эссе. В отдельном редакторе меняются порядок и границы сцен, хук, заголовок, тезис, вопрос и субтитры. Сохранение пересобирает только выбранный ролик.
5. **Постинг.** Проверьте обложку, заголовок, описание, главы, хештеги и комментарий. Обложку можно перегенерировать с другим кадром без повторного рендера эссе. Публикация поддерживает YouTube и Telegram; TikTok подключается настройкой. Статус отправок хранится в выпуске.

Открытие шага не запускает анализ или рендер само по себе. Каждая генерация, пересборка и публикация начинается отдельной командой.

## Установка и запуск

Релиз доступен в разделе [GitHub Releases](https://github.com/se1dhe/shortcuts/releases). Для разработки требуется macOS 15+, Xcode со Swift 6 и XcodeGen. Apple Silicon нужен для локального MLX-инференса; `ffmpeg`/`ffprobe` используются для обработки медиа и могут быть получены приложением.

```sh
xcodegen generate
xcodebuild build \
  -project Shortcast.xcodeproj \
  -scheme Shortcast \
  -configuration Debug \
  -derivedDataPath .build \
  CODE_SIGNING_ALLOWED=NO
```

Локальный успешный build устанавливает и регистрирует одну актуальную копию `/Applications/КАДР & СЕНС.app` (или `~/Applications`, если системная папка недоступна). При разработческой сборке без установки передайте `SHORTCAST_SKIP_INSTALL=1` в окружение `xcodebuild`.

## Модели и подключение сервисов

- Director использует локальную языковую/визуальную модель, настроенную в приложении; MLX-стек требует Apple Silicon.
- WhisperKit подключается для транскрипции, когда рядом с видео нет подходящих субтитров.
- Публикация требует авторизации YouTube/TikTok и настройки Telegram-бота и канала. Учётные данные и файлы проектов не входят в репозиторий.
- Доступность внешних сервисов определяется их API, авторизацией и настройками канала.

## Разработка

```sh
xcodegen generate
SHORTCAST_SKIP_INSTALL=1 xcodebuild build \
  -project Shortcast.xcodeproj \
  -scheme Shortcast \
  -configuration Debug \
  -derivedDataPath .build \
  CODE_SIGNING_ALLOWED=NO
node --test scripts/browser-publisher/test/*.test.js
```

Live-проверки моделей и рендера требуют специальных переменных окружения. Обычные проверки не публикуют контент.

## Структура репозитория

- `Shortcast/` — нативное приложение SwiftUI.
- `ShortcastTests/` — модульные проверки моделей, Director-пайплайна и редакторов.
- `scripts/browser-publisher/` — браузерная автоматизация публикации.
- `Vendor/gemma-4-swift-mlx/` — исходный код vendored MLX-зависимости.
- `docs/` — техническое описание и проектирование.
- `site/` — статическая страница GitHub Pages, её ресурсы и обработанные скриншоты.
- `branding/`, `channels_plan/` — материалы бренда и канала.

Фильмы, пользовательские субтитры, проекты, локальные модели, экспорты, авторизация, логи и кэши — локальные данные. `.gitignore` исключает пользовательские видео и артефакты сборки.
