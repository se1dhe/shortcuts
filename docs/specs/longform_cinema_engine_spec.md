# Спецификация: Long-form Thematic Cinema Engine (Формат @prrodan)

## 1. Обзор и бизнес-цель
Добавление в Shortcast нового режима генерации длинных YouTube-видео (16:9, хронометраж 5–8 минут) на основе полнометражных фильмов в формате **Thematic Supercut / Кинематографическое философское эссе** по эталонам канала [@prrodan](https://www.youtube.com/@prrodan/videos).

В отличие от 60-секундных шортсов, движок длинного метра берет одну философскую тему фильма («Терпение», «Гениальность», «Характер», «Жалость», «Трудность») и собирает цельную 4-актную драматическую арку из 4–8 ключевых сцен фильма, накладывая сквозной атмосферный саундтрек и фирменный центрированный визуальный титр.

---

## 2. Архитектура и принципы SOLID

Система проектируется строго по принципам SOLID и разделяется на независимые сервисы:

```
┌────────────────────────────────────────────────────────────────────────┐
│                      LONG-FORM CINEMA ENGINE                           │
├────────────────────────────────────────────────────────────────────────┤
│ 1. ThematicConceptDiscovering (LongformThematicService)                │
│    • Анализ транскрипта фильма и генерация 3-5 сильных тем + слоганов  │
│    • Возможность ручного ввода концепта пользователем                  │
├────────────────────────────────────────────────────────────────────────┤
│ 2. LongformNarrativeDirecting (LongformNarrativeDirector)              │
│    • Отбор 4-8 ключевых сцен из фильма с формированием 4-актной арки: │
│      [Хук & Тезис] → [Падение & Боль] → [Борьба] → [Катарсис & Финал]  │
│    • Суммарный целевой хронометраж: строго 300 - 480 секунд (5-8 мин)  │
├────────────────────────────────────────────────────────────────────────┤
│ 3. LongformAudioMasteringProtocol (LongformAudioMasteringService)      │
│    • Наложение сквозного кинематографического саундтрека               │
│    • Плавный crossfade аудиостыков между сценами                       │
│    • Динамический sidechain ducking музыки под диалоги                 │
│    • Эмоциональное крещендо (нарастание громкости на кульминации)      │
├────────────────────────────────────────────────────────────────────────┤
│ 4. LongformSubtitleRenderingProtocol (LongformSubtitleRenderer)        │
│    • Отрисовка фирменного стиля @prrodan:                              │
│      - Центральный якорный титр темы: Center X, Center Y, Bold White   │
│      - Синхронные реплики диалогов прямо под ним: Accent Yellow/Red    │
├────────────────────────────────────────────────────────────────────────┤
│ 5. LongformRenderingProtocol (LongformClipRenderingService)            │
│    • Сборка горизонтального видео 16:9 (1920x1080) через AVFoundation  │
│    • Высокоскоростной экспорт с сохранением оригинального качества     │
├────────────────────────────────────────────────────────────────────────┤
│ 6. LongformMetadataGenerating (LongformMetadataGenerator)              │
│    • Генерация вирусного заголовка от 2-го лица («Ты поймешь...»)      │
│    • Философское описание-манифест + теги + Fair Use дисклеймер        │
└────────────────────────────────────────────────────────────────────────┘
```

### Декомпозиция по SOLID:
- **Single Responsibility (SRP)**:
  - `LongformThematicService` отвечает только за выявление философских тем.
  - `LongformNarrativeDirector` отвечает только за подбор сцен и драматургию.
  - `LongformAudioMasteringService` отвечает только за сведение непрерывной музыки и диалогов.
  - `LongformSubtitleRenderer` отвечает только за визуализацию центрированного текста.
  - `LongformClipRenderingService` отвечает только за видеомонтаж и экспорт AVFoundation.
- **Open/Closed (OCP)**:
  - Сервисы работают через протоколы (`LongformNarrativeDirecting`, `LongformAudioMasteringProtocol`, `LongformSubtitleRenderingProtocol`), что позволяет легко расширять стили монтажа и титров без изменения существующего кода.
- **Liskov Substitution (LSP)**:
  - Любая реализация рендера или аудиомастеринга взаимозаменяема в тестовой среде и продакшене.
- **Interface Segregation (ISP)**:
  - Протоколы минималистичны и специализированы (нет громоздких «божественных» интерфейсов).
- **Dependency Inversion (DIP)**:
  - Высокоуровневый `LongformPipelineCoordinator` внедряет зависимости через абстрактные протоколы, а не конкретные классы.

## 3. Модели данных (Domain Models)

```swift
/// Формат выходного видео
enum CinemaOutputFormat: String, Codable, CaseIterable, Identifiable {
    case shortSquare = "Шортс 1:1"
    case shortVertical = "Шортс 9:16"
    case longformLandscape = "Длинный метр 16:9"
    
    var id: String { rawValue }
    var targetSize: CGSize {
        switch self {
        case .shortSquare: return CGSize(width: 1080, height: 1080)
        case .shortVertical: return CGSize(width: 1080, height: 1920)
        case .longformLandscape: return CGSize(width: 1920, height: 1080)
        }
    }
}

/// Философский концепт фильма
struct ThematicConcept: Codable, Identifiable, Equatable, Hashable {
    var id: String { word }
    var word: String                    // Например: "Терпение", "Гениальность", "Характер"
    var tagline: String                 // Короткий слоган
    var philosophicalPremise: String    // Описание идеи
    var suggestedTitle: String          // Заголовок YouTube от 2-го лица
    var accentColorHex: String          // "#F5D020" (желтый) или "#E50914" (красный)
}

/// Драматургический акт в длинном видео
enum LongformActType: String, Codable {
    case hook = "Хук и Тезис"
    case downfall = "Падение и Испытание"
    case struggle = "Борьба и Упорство"
    case catharsis = "Катарсис и Прорыв"
}

/// 4-актная арка длинного ролика
struct LongformNarrativeArc: Codable, Identifiable, Equatable {
    var id: String
    var movieTitle: String
    var concept: ThematicConcept
    var segments: [TimeSegment]         // 4-8 сегментов общей длительностью 300-480с
    var totalDuration: Double { segments.reduce(0) { $0 + $1.duration } }
    var acts: [LongformAct]
    var mood: String
    var summary: String
}

/// Метаданные для YouTube
struct LongformYouTubeMetadata: Codable, Equatable {
    var title: String
    var description: String
    var tags: [String]
    var pinnedComment: String
}
```

## 4. Визуальные спецификации рендеринга (Brand Signature UI)

1. **Разрешение**: 1920x1080 (Landscape 16:9).
2. **Якорный титр темы**:
   - Позиция: Абсолютный центр экрана `(x: 0.5 * W, y: 0.5 * H)`.
   - Шрифт: Жирный современный гротеск (Russo One / Montserrat-Black / Bebas Neue), кегль ~40–46pt
     при эталонных 1080 строках (единый масштаб `k = renderSize.height / 1080`).
   - Авто-усадка: слово обязано влезать в ≤60% ширины кадра; кегль снижается автоматически
     с пола `30pt · k` ниже опускать нельзя.
   - Цвет: Офф-вайт `#F5F5F7` (или `#FFFFFF`) с контрастной обводкой и мягкой кинематографической тенью.
   - Поведение: Статично присутствует на протяжении всей арки, формируя смысловой фокус.
3. **Синхронные субтитры диалогов**:
   - Позиция: Центрированы по горизонтали ровно под якорным словом (отступ от нижнего края титра).
   - Кегль: ~30–34pt · k (субтитры должны читаться с телефона: 26pt на 1080p ≈ 9px на мобильном экране).
   - Шрифт: Чистый читаемый гротеск.
   - Цвет: Акцент темы (`#F5D020`, `#E50914` и т. п.), **но только прошедший WCAG AA 4.5:1**
     против светлоты кадра (эталон `backgroundL = 0.02`): при недостатке контраста цвет
     поднимается по яркости HSB с сохранением тона.
   - Поведение: Сменяются построчно, строго синхронно со словами персонажей.
4. **Читаемость поверх кадра (обязательно)**:
   - Любой акцентный текст (субтитры, надстрочники карточек актов) должен держать контраст ≥4.5:1
     к фону кадра; обводка и кино-тень — единственный разрешённый способ повышения читаемости.
   - Плашки, рамки, подложки, blur-фоны под текстом запрещены.
   - Типографика оверлея и превью (`renderPreviewImage`) берется из одного источника констант.

## 5. Спецификации звука (Audio Mastering)

1. **Сквозной саундтрек**:
   - Непрерывный атмосферный трек из `Resources/Music/` (например, `Dramatic_Emotional_Theme.m4a`, `Tension_Dark_Suspense.m4a` или кастомный трек пользователя).
   - Длительность лупится или растягивается с плавным развитием.
2. **Сведение и дакинг**:
   - Нормализация голоса фильма (диалоги): `-1.0 dBFS`.
   - Громкость фоновой музыки во время речи: `-18 dBFS .. -22 dBFS` (приглушение на 12–14 dB).
   - Громкость фоновой музыки в паузах между репликами: `-8 dBFS .. -12 dBFS`.
   - Финальное крещендо (последние 40–60 секунд): нарастание до `-2 dBFS` под кульминационные кадры.
3. **Аудиостыки между сценами**:
   - Экспоненциальный кроссфейд (0.35–0.50 сек) диалоговых дорожек во избежание резких щелчков.

## 6. Пользовательский сценарий (User Experience Flow)

1. **Выбор формата**:
   - На стартовом экране (`DropZoneView` / `ContentView`) пользователь переключает режим:
     `[ 📱 Шортс (1:1 / 9:16) ]`  |  `[ 🎬 Длинный ролик (16:9 YouTube) ]`
2. **Дроп фильма**:
   - Пользователь перетаскивает MKV/MP4 файл фильма.
3. **Анализ и выбор лейтмотива**:
   - Приложение быстро запускает поиск тем (`LongformThematicService`).
   - Отображается экран с 3–5 карточками концептов (например: ⏳ *«Терпение»*, 🧠 *«Гениальность»*, ⚔️ *«Характер»*) + поле для ввода собственного слова.
4. **Генерация арки**:
   - LLM формирует 4-актный таймлайн (5–8 минут ключевых сцен).
5. **Рендеринг и Мастеринг**:
   - Прогресс-бар отображает этапы (Склейка сцен → Саундтрек & Ducking → Титры 16:9 → Экспорт).
6. **Готовый результат (`LongformResultsView`)**:
   - Плеер 16:9 с готовым видео.
   - Кнопка «Скопировать заголовок YouTube» (например, *«Иногда, чтобы победить, нужно перестать быть удобным.»*).
   - Кнопка «Скопировать описание-манифест».
   - Кнопка «Экспортировать в файл» / «Открыть в Finder».

## 7. Примечание от 2026-10-19: правка кеглей титров (пункт 4)

Исторически пункт 4 предписывал якорному титру темы кегль «~48–56pt», а субтитрам — «~18–22pt
(~30% от размера заголовка)». Именно эта норма делала надпись темы гигантской: на готовом
`longform_субъективность_262965.mp4` (1920x1080@30) слово темы занимало почти половину ширины кадра,
а субтитры 26pt превращались в ~9px на мобильном экране и дополнительно тонули в произвольном
кадре фильма (контраст акцентного цвета ~1.2:1 в тёмных сценах).

Пункт 4 переписан: титр темы ~40–46pt с авто-усадкой до ≤60% ширины кадра (пол 30pt·k),
субтитры ~30–34pt, акцентный текст держит WCAG AA 4.5:1 против кадра. Порядок слоев
(слово темы → субтитры под ним → слоган/водный знак под субтитрами) и запрет на плашки/рамки
остаются неизменными контрактами. Все кегли масштабируются множителем `k = renderSize.height / 1080.0`;
на эталонном рендере 1920x1080 `k = 1.0`, поэтому правка меняет только кегли, а не геометрию.
