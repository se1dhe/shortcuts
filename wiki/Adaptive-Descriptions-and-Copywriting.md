# Адаптивный копирайтинг и метаданные (Adaptive Copywriting)

## 1. Проблема: Жестко закодированные шаблоны («Захардкоженный шлак»)

### 1.1. В модуле Шортсов (`CinemaContentGenerator.swift`)
В настоящее время для любого фильма (будь то комедия, драма или триллер) генерируются одни и те же строковые константы:
- **Хук TikTok / Reels:** `"Такой развязки никто не ожидал... 😳"`
- **Хук YouTube Shorts:** `"Такой развязки точно никто не ожидал... 😳 #Shorts"`
- **Описание:**  
  `"Такой развязки точно никто не ожидал... 😳\n\nКак бы ты поступил на его месте? Напиши в комменты 👇\n\n🍿 Название фильма и где посмотреть уже выложили в наш Telegram: @telonyx_club"`

### 1.2. В модуле Кино-эссе (`LongformMetadataGenerator.swift`)
- Заголовки роликов выбираются через оператор остатка от деления `% templates.count` из 5 фиксированных фраз:
  - *«Ты проигрываешь, пока веришь в это | [Слово]»*
  - *«Однажды ты поймёшь, почему всё произошло именно так | [Слово]»*
  - *«Иногда, чтобы победить, нужно отпустить контроль | [Слово]»*
- Описание представляет собой общий текст, повторяющийся для всех кино-эссе:
  *«Этот ролик — про другую сторону... Не про внешние декорации. Не про слова на поверхности...»*

## 2. Архитектура решения: Нейросетевая генерация метаданных (LLM)

### 2.1. Протокол генерации метаданных (DIP)
```swift
protocol CinemaCopywritingServiceProtocol: Sendable {
    func generateShortsCopy(
        movie: MovieIdentity?,
        sceneTranscript: String,
        candidateWhy: String,
        platform: SocialPlatform,
        genre: CinemaGenreMode
    ) async throws -> GeneratedSocialPost

    func generateLongformMetadata(
        movieTitle: String,
        movieOverview: String,
        concept: ThematicConcept,
        acts: [LongformAct]
    ) async throws -> LongformYouTubeMetadata
}
```

### 2.2. Промпты для Шортсов под конкретные соцсети
Модель (Qwen / Gemma) получает на вход:
1. Название фильма, год выпуска, жанр, режиссера.
2. Конкретный диалог из вырезанной сцены.
3. Обоснование драматического конфликта (`candidate.why`).

#### Выходной формат (JSON):
```json
{
  "hook": "Ударная фраза на экране и заголовок (до 60 символов)",
  "description": "Интригующее описание ситуации конкретного персонажа",
  "callToAction": "Вопрос к аудитории по моральной дилемме сцены",
  "hashtags": ["тег1", "тег2", "тег3"]
}
```

#### Специфика платформ:
- **TikTok:** Сверхкороткий заголовок, фокус на эмоциональном взрыве, трендовые теги.
- **Instagram Reels:** Фокус на кинематографичности, атмосфере и визуальном стиле, призыв сохранить.
- **YouTube Shorts:** Кликбейтный, но содержательный заголовок с `#Shorts`, вопрос для закрепленного комментария.
- **Telegram:** Полная информационная карточка фильма: год, актеры, оценка IMDb, авторская рецензия момента.

### 2.3. Промпты для Кино-эссе (Longform)
Модель анализирует 4-актную драматургическую арку фильма и философскую тему (`ThematicConcept`):
- **Заголовок:** Уникальное название эссе, бьющее в нерв темы фильма (например: *«Бойцовский клуб: почему мы уничтожаем то, что любим»*).
- **Описание-манифест:** Авторский разбор конфликта персонажей без абстрактных штампов.
- **Таймкоды:** Точный расчет по секундам глав фильма.
- **Теги:** Семантическое облако фильма, темы, актеров и режиссера.
