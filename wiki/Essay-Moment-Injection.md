# Врезка культовых сцен в кино-эссе (Essay Moment Injection)

## 1. Проблема
При создании 4-актного кино-эссе (хронометраж 7–10 минут) языковая модель выстраивает драматическую арку, но может пропустить ключевую культовую сцену.
*Пример:* В фильме *«Бойцовский клуб»* в финальном акте (Катарсис) модель собрала отличную кульминацию, но не добавила в самый конец культовую фразу:  
> *«Мы встретились в странный период моей жизни»* на фоне падающих небоскребов под Pixies.

Пользователю требуется возможность:
1. Выполнить поиск по полной транскрибации фильма по ключевым словам фразы.
2. Просмотреть контекст диалога до и после фразы.
3. Выбрать границы начала (In-Point) и конца (Out-Point) фрагмента.
4. Выбрать точку врезки: **В начало акта** (вступление/хук) или **В конец акта** (финальный аккорд/кода).
5. Применить кинематографический переход через мягкое затухание в темноту и проявление (Dip-to-black / Crossfade).
6. Автоматически пересобрать весь проект: пересчитать таймлайн, наложить субтитры Whisper, обновить аудио-мастеринг и таймкоды глав для YouTube.

---

## 2. Архитектура решения

### 2.1. Сервис поиска по транскрипту (`TranscriptMomentSearchService`)
```swift
protocol TranscriptMomentSearching: Sendable {
    func search(query: String, in transcript: Transcript) -> [TranscriptSearchResult]
    func surroundingContext(for segment: TranscriptSegment, in transcript: Transcript, paddingSeconds: Double) -> (start: Double, end: Double, text: String)
}
```

- Полнотекстовый регистронезависимый поиск по `transcript.segments`.
- Поддержка поиска по нескольким словам с ранжированием по релевантности.
- Автоматическое расширение интервала на безопасную паузу (1.5–3 с) до первой реплики и после последней.

### 2.2. Интерфейс добавления сцены (`ActMomentInjectionSheet`)
- Встраивается в `LongformActEditorView.swift` через кнопку:
  `[ + Вставить культовый момент из фильма ]`
- Компоненты окна:
  - Поисковая строка с моментальной фильтрацией.
  - Список совпадений с указанием таймкода и цитаты.
  - Встроенный видеоплеер для верификации кадра.
  - Кнопки точной подстройки границ: `[-1с]`, `[-0.2с]`, `[+0.2с]`, `[+1с]`.
  - Выбор позиции: *«В начало акта»* / *«В конец акта»*.

### 2.3. Переходы и пересборка таймлайна (`LongformPipelineCoordinator`)
1. **Генерация перехода `LongformCutTransition`:**
   - Для врезанной сцены создается мягкое кинематографическое затемнение:
     - Fade-out: 0.35–0.45 с до черного экрана.
     - Inter-scene pause: 0.5–0.8 с (слышна только фоновая музыка).
     - Fade-in: 0.45 с появление новой сцены.
2. **Синхронизация субтитров:**
   - Новая сцена автоматически сопоставляется с `transcript.segments`:
     ```swift
     let matchingSegments = transcript.segments.filter {
         $0.end > newSegment.start && $0.start < newSegment.end
     }
     ```
   - Субтитры смещаются на таймлайн композиции.
3. **Обновление метаданных:**
   - Функция `buildChapters` пересчитывает таймкоды YouTube с учетом добавленной длительности.
   - `LongformAudioMasteringService` плавно дакирует музыку под добавленные реплики.
