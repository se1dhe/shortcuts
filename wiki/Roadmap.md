# Дорожная карта реализации (Roadmap)

Данный план предназначен для выполнения AI-агентами и разработчиками. Каждая задача автономна, верифицируема unit-тестами и строго следует SOLID.

---

## Фаза 1: Устранение крэшей рендеринга шортсов (P0)

- [ ] **1.1. Безопасные рампы громкости в `SinglePassClipCompositor.swift`**
  - Реализовать `safeSetVolumeRamp(params:from:to:start:duration:lastRampEnd:)`.
  - Заменить циклы установки громкости дакинга и финального фейда на безопасный планировщик.
  - Объединять фразы с паузой $< 0.4$ с в непрерывный дакинг.
  - *Критерий приемки:* Unit-тест с серией пересекающихся интервалов субтитров отрабатывает без исключений AVFoundation.

- [ ] **1.2. Валидация Transform Ramps в `SinglePassClipCompositor.swift`**
  - Добавить проверку `clampedT2 - t1 >= 0.05` перед вызовом `setTransformRamp`.
  - Устранить передачу нулевых интервалов в AVVideoComposition.

- [ ] **1.3. Оптимизация памяти при нарезке шортсов в `WorkspaceModel.swift`**
  - Исключить повторный вызов WhisperKit для каждого фрагмента; использовать сдвиг меток исходного транскрипта.
  - Вызывать `modelManager.freeDirectorIfMemoryTight()` перед пакетным экспортом.
